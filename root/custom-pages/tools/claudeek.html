Claudeek

一个装在 U 盘里、双击就能用的 AI 工作站。走到哪，AI 就跟到哪。

内测特惠 · 专业版限量 50 份

Claudeek 是一个便携 AI 工作环境。它把强大的 AI 对话能力（基于 Claude Code）和你所有的对话记忆打包在一个文件夹里——复制到 U 盘上，插上任何一台 Windows 或 Mac 电脑，双击就能开始工作。

本质上，它和 ChatGPT 的差别在于：ChatGPT 是别人家的服务器上跑的一个网页；Claudeek 是你自己的工具——所有对话记录存在你的 U 盘上，你的 API Key 花你自己的钱按量付费，换电脑不需要重新登录、重新配置。拔掉 U 盘，什么痕迹都不留在电脑上。

首次在一台新电脑上使用时，内置的开荒程序会自动安装所需软件（Python、Git、Node.js、VS Code 等）。之后每次使用——插上、双击、输入 PIN 码——即刻进入工作状态。

它能做什么

写代码

描述你要什么功能，AI 写出完整可运行的代码。支持 Python / JavaScript / Go / Rust / Shell 等几乎所有语言。它不是为了聊天而生的——它就是为编程而生的。

跨会话记忆

聊完退出后，对话摘要自动写入本地向量库。下次启动 AI 会自动检索相关记忆，它会记得你们上次聊到哪里。这是网页版 ChatGPT 做不到的。

联网搜索

AI 可以直接上网搜索然后总结给你。查文档、找方案、追踪最新技术动态，不需要你在搜索引擎和 AI 之间来回粘贴。

写文案

文章、邮件、报告、翻译、润色——告诉它需求，它输出成品。不是那种一眼 AI 味的模板化回答，你可以自定义它的写作风格和角色设定。

多终端自由选

CMD、PowerShell、VS Code——你想在哪写就在哪写。程序员可以选择 VS Code 边看代码边聊，普通用户可以用命令行。三种终端，同一套环境。

数据 100% 在你手里

没有云端账号，没有服务器存储，没有遥测上报。你的 API Key、对话记录、AI 行为设定全部在一个文件夹里。备份 = 复制这个文件夹。丢了 = 从备份恢复。

自定义 AI 角色

编辑一个 Markdown 文件，就能设定 AI 的身份、语气、代码风格和回复语言。让 AI 变成资深后端工程师、学术翻译、或是英文写作教练——角色随你定义。

后台守护，不怕忘存档

即使你偶尔忘记手动归档，后台守护进程会自动扫描新对话并生成摘要同步到记忆库。偶尔疏忽不会导致记忆永久丢失。

持续更新

一条 git pull 命令即可更新到最新版，或通过内置的 update_checker 一键检查。更新只替换核心程序，你的 API Key、AI 设定和对话记录不会被覆盖。

Windows 和 Mac 都能用

支持 Windows 10/11 和 macOS 12+。U 盘用 exFAT 格式格式化后两边都能读写，同一块盘在公司和家里的不同电脑之间自由切换。

购买前你可能会问

买了之后 AI 对话免费吗？

Claudeek 本身不收取 AI 对话费用。对话通过 DeepSeek API 实现，你需要自己注册 DeepSeek 和硅基流动账号（免费），按用量付费。DeepSeek 目前的价格大约是每 100 万 token 2 元，日常使用一个月几块钱就够了。

和直接装 Claude Code 有什么区别？

Claudeek 解决的是"环境"和"持续记忆"两个问题。你不用装 Python、Node.js、Git，不用配环境变量，不用折腾命令行——插上 U 盘双击就行。另外它也提供了 ChatGPT 没有的跨会话记忆、自动归档、后台守护等全套工程化功能。

能在多台电脑上同时用吗？

标准版绑定 1 台设备。专业版可以绑定 3 台设备，但不支持同时在线——你可以白天在公司用，晚上在家用，换机时输入 PIN 码自动切换，不需要重新激活。

换了电脑 / 重装了系统，激活码还能用吗？

可以。把 Claudeek 文件夹拷到新电脑，输入 PIN 码后云端自动检测并静默换绑。专业版 3 台配额满后还可以自助顶掉旧设备（每 30 天限 1 次）。不需要联系开发者。

忘记 PIN 码了怎么办？

连续输错 5 次 PIN，本地快捷登录失效。掏出你保存的完整激活码重新验证，设一个新 PIN 即可。激活码就是你最终的"恢复钥匙"——请妥善保管。

有免费试用吗？

暂时没有。但标准版 ¥99/年，比 ChatGPT Plus 一个月的订阅费还便宜。专业版 ¥199 买断——如果你打算长期用，这个价格用一年就回本了。

API Key 怎么获取？

购买后软件内有详细的图文引导，帮你注册 DeepSeek 和硅基流动账号并获取 API Key。全程约 5 分钟，不需要技术背景。
